# plan: MancuTG-backend

## Objective

Provide optional additive services for shared event ingestion, media/session handling, sync pathways, and integrations without becoming a hard dependency for ArenaC local value.

## Current backend responsibilities

- Validate and ingest app-spanning session/event batches (`/events`).
- Persist events/sessions/media metadata (currently JSON-backed runtime store).
- Handle media session path (`/media/sessions`).
- Provide health and integration endpoints (`/health`, `/integrations/archidekt/:deckId`).

## Explicit non-goals (current cycle)

- Full multi-user production auth model.
- Final relational production persistence rollout.
- Complete replay/query surface for tournament analytics.

## Data and consistency model

- Append-only event intake.
- Dedupe by protocol identity and optional batch idempotency key.
- Projector-based truth model for future review/correction/tournament state.
- Keep compatibility with both ArenaC and PaperC producers.

## Near-term backend milestones

1. Harden event/media ingestion contracts and error handling.
2. Keep ArenaC-required APIs stable for MVP release operations.
3. Prepare interfaces for review/projector expansion without breaking current routes.

## Longer-term backend milestones (post-ArenaC MVP)

- Review queue and correction APIs.
- Concurrent stream worker partitioning.
- Relational persistence migration.
- Auth/roles/permissions.
- Query/replay/tournament APIs.
