# plan: MancuTG-ArenaC

## Product objective

Deliver a presentable, functional, Windows-first Arena companion with easy setup and stable local workflows.

## MVP scope (current cycle)

- Overwolf windowed UI for setup and daily use.
- Rust sidecar service (`mancutg-arenac serve`) for all core operations.
- Local log bootstrap/watch, store inspection, diagnostics, iOS offline import, settings/consent, backup export.
- No in-game HUD/overlay in this MVP.

## UX expectations

- Setup detects default `Player.log` path and lets user correct path.
- Start/stop watcher with clear running state.
- View local: history, collection, inventory, draft, diagnostics.
- One-click local cleanup and backup export.
- Privacy and consent toggles are visible and persisted.

## Technical responsibilities

- Rust core: parsing, checkpoints, session/event persistence, settings.
- UI: orchestration and display, never source of domain truth.
- API client: typed mapping from service DTOs to route/view state.

## Known limits

- MTGA parser coverage is meaningful but not yet full production coverage.
- No overlay/HUD, no replay UI, no installer-grade signed package path fully automated.
